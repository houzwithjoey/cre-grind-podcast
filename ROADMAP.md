# CRE Grind Podcast — Roadmap

Format: two hosts. MAYA (host, sharp questioner, thinks like a career-switcher heading into credit) and DEV (former CRE credit lender/special-servicing veteran, explains with numbers). 30–50 min per episode, one topic.
Rotation: Concept → Asset type → Market/news. Focus markets when examples are needed: New York, New Jersey, Texas.
Seasons: 24 episodes each (about six months of weekly episodes). Episode numbers run continuously across seasons.
Joey can request topics anytime; requested topics jump the queue.
